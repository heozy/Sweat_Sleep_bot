Sweat_sleep_bot

Я хочу представить вам проект Sweat_sleep_bot. Он представляет собой telegram бота, залача которого решить проблемы полльзователя со сном посредством сбора информации о вашем сне, настроении и самочувствии. Также бот булет предлагать пройти несколько советов по улучшению сна, а также предложит несколько полезных привычек, которые помогут вам засыпать легче, спать крепче и просыпаться в хорошем настронии!

Реализуемый функционал:
1. Проведение утреннего опроса пользователя по качеству его сна, настронию и состоянию. Сбор и обработка полученных данных в статистику, которую пользователь может узнать в любой момент.
2. Вечерние советы по улучшению сна. В них пользователю будет предложено узнать полезную и интересную информацию о сне, основанную на достоверных научных исследованиях. Также из них пользователь узнает о полезных привычках, которые после будут добавлены в его библиотеку советов.
3. Библиотека советов - это список полезных предсонных и утренних привычек, следование которым помогут вам улучшить ваш сон и пробуждение.
4. Определение удобного для пользователя времени взаимодействия с ботом. Пользователь при настройке бота указывает время утром и вечером, когда он смодет пройти опрос и прочитать совет соответственно. В указанное время бот отправит ему сообщение, в котором предложит пройти ту или иную активность.
5. Интерфейс команд, в которомпользователь сможет изменить настройки бота, узнать статистику, посмотреть советы.

Архитектура:

- Функции:

first_contact - Первая, главная функция программы. В ней прописан "первый контакт" с ботом, а также условия, необходимые для работы той или иной функции бота
information - Функция, в которой описан первый диалог с ботом, знакомство с ним
valid_time_format - Функция для проверки правильности формата введённого времени
chose_time - Первыя из двух функций для установки времени отправки ботом сообщений
chose_time_2 - Вторая функция для установки времени отправки ботом сообщений
save_time - Функция для сохранения выбранного пользователем времени 
schedule_user_messages - Фунция установки времени отправи сообщений для бота
send_morning_message - Начальная функция для отправки пользователю утренего сообщения
survey_handler - Функция для обработаки ответа пользователя
ask_survey_question - Функция для проведения опроса
survey_response - Функция для сохранения полученных их опроса данный. а также для логического следования опроса
send_evening_message - Функция для оправки вечернего сообщения 
get_sleep_tip - Функция для выбора совета для вечернего сообщения
menu - меню
menu_selection - Выбор пунктов меню. Выполнение соответствующих действий
get_sleep_statistics - Получение статистики о пользователе для её дальнейшего вывода

- Словари:

users - словарь с пользователями бота

- Структуры:

User - структура, хранящая данные о пользователе
Атрибуты структуры:
chat_id - id чата с пользователем
message_time_morning - время для утреннего сообщения
message_time_evening - время для вечернего сообщения
survey_data - список с собранными данными о сне пользователя
tips_received - список с полученныыми советами
tips_sent - количество советов, уже отправленных пользователю
survey_in_progress - логическая переменная, хранящая информацию о состоянии утреннего опроса
current_survey_step - текущий шаг опроса
current_survey_data - текущие данные из опроса

Инструкция по запуске бота:
1. Открыть программу
2. Установить все необходимы библиотеки в вертуальную среду (список нужных библиотек в файле requirements.txt) 
3. Запустить программу через терминал
4. Зайти в телеграмм бота и пользоваться им. (ссылка https://t.me/SweetSleep_44_Bot)
