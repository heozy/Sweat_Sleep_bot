Sweat_sleep_bot

Привет! Я хочу представить вам проект Sweat_sleep_bot. Он представляет собой telegram бота, залача которого решить проблемы полльзователя со сном посредством сбора информации о вашем сне, настроении и самочувствии. Также бот булет предлагать пройти несколько уроков по улучшению сна, а также предложит несколько полезных привычек, которые помогут вам засыпать легче, спать крепче и просыпаться в хорошем настронии!

Реализуемый функционал:
1. Проведение утреннего опроса пользователя по качеству его сна, настронию и состоянию. Сбор и обработка полученных данных в статистику, которую пользователь может узнать в любой момент.
2. Вечерние уроки по улучшению сна. В них пользователю будет предложено узнать полезную и интересную информацию о сне, основанную на достоверных научныз исследованиях. Также из них пользователь узнает о полезных привычках, которые после прохождения урока будут добавлены в его "сонный" ритуал.
3. Функция "сонного" ритуала - это список полезных предсонных и утренних привычек, следование которым помогут вам улучшить ваш сон и пробуждение.
4. Определение удобного для пользователя времени взаимодействия с ботом. Пользователь при настройке бота указывает время утром и вечером, когда он смодет пройти опрос и прочитать урок соответственно. В указанное время бот отправит ему сообщение, в котором предложит пройти ту или иную активность.
5. Интерфейс команд, в которомпользователь сможет изменить настройки бота, узнать статистику, посмотреть привычки и перечитать уроки.

Архитектура:

- Функции:

1. Morning_stat() //статистика, которую бот будет получать от пользователя из опроса, который будет предлагаться к прохождению каждое утро.
2. Evening_lesson() //фунция, вызывающая вечернее сообщение бота
3. Ready() //узнаёт о готовности пользователя к прохождению активностей
4. Start() //самое первое взоимадействие с ботом (настройка, объяснение правил и т.д.)
5. Data() //функция, которая узнаёт удобное для пользователя время.
6. Settings() //перенаправляет пользователя в настройки
7. Stat() //по вызову предоставляет пользователю статистику
8. Rutin() //по вызову перенаправляет пользователя в список его привычек
9. Lesson() //по вызову начинает урок
10. Lesson_list() //по выхову перенаправляет пользователя в список уроков.

- Структуры:

1. opros() //структура опроса
2. stat() //структура статистики
3. settings() //структура настроек

P.s. Список архитектуры будет пополняться по мере выполнения проекта.
